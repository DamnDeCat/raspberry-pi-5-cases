# 树莓派 3 / 树莓派 5 3D 打印外壳

这是一个用于 **Raspberry Pi 3 和 Raspberry Pi 5 的 3D 打印保护外壳模型**，主要用于保护树莓派主板，减少日常使用过程中主板受到碰撞、灰尘以及意外接触造成损伤的可能。

模型采用 3D 打印方式制作，针对树莓派主板的接口和实际使用需求进行了相应的开孔设计，在提供基本保护的同时，尽量保证主板各接口能够正常使用。

## 关于模型来源

### Raspberry Pi 3

树莓派 3 的外壳模型来自网络，经过整理后保存在本项目中。

由于文件保存时间较久，目前已经无法确认原始作者及最初发布出处。如果你知道该模型的原始作者或来源，欢迎联系我，我会及时补充相关信息并进行署名。

### Raspberry Pi 5

树莓派 5 的外壳模型是在上述树莓派 3 外壳模型的基础上进行修改和适配的。

主要针对 Raspberry Pi 5 的主板尺寸、接口位置以及 SD 卡使用方式进行了调整，并根据实际使用情况对部分结构进行了修改。

因此，树莓派 5 的模型属于基于原有模型的修改版本，并非完全从零开始设计。
